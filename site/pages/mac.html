AI meeting notes for Mac, without a meeting bot

MeetMind records your Mac's audio and microphone during any call, then writes a transcript and minutes with decisions and action items. Free and open source, for Apple silicon and Intel Macs.

Download for Mac Install steps

MeetMind-__VERSION__-arm64.dmg (Apple silicon) or -x64.dmg (Intel) · macOS 14.2 or later

In short

MeetMind for macOS is a free beta for macOS 14.2 or later. It records the other participants with the system audio capture Apple added in macOS 14.2, and you with your microphone, so it works with Zoom, Google Meet, Teams or any other app without a bot. It isn't signed by Apple yet, so the first launch takes one extra step.

Install MeetMind on a Mac

  1. From the latest release, download MeetMind-x.y.z-arm64.dmg for Apple silicon (M1 and later) or MeetMind-x.y.z-x64.dmg for Intel Macs. Open it and drag MeetMind to Applications.
  2. Open MeetMind. macOS says it can't verify the developer: click Done, open System Settings › Privacy & Security, scroll down and click Open Anyway. On macOS 15 and later, Control-clicking the app and choosing Open no longer works for unsigned apps.
  3. In Settings › System › Permissions, allow Microphone and Screen & System Audio Recording. The second one is what records the other participants.
  4. Play a video and use Settings › System › Test system audio to check that MeetMind hears your Mac. If the selected capture method stays silent, try the others and keep the one that works.
  5. Add a speech-to-text key and a notes key (Gemini, Groq or Claude) in Settings. FFmpeg is already included.

Recording a call

Automatic meeting detection isn't available on macOS yet, so start a recording in one of these ways:

  • the Record button in the app or the menu bar icon;
  • the reminder MeetMind shows when a meeting in your connected calendar (Google, Outlook, iCloud or any ICS link) starts;
  • the optional Chrome extension's button inside Google Meet and Zoom tabs.

After you stop, the recording is transcribed and the notes stream in as the model writes them: an executive summary, agenda, key decisions and an action items table with owners and deadlines.

What "beta" means on macOS

  • The app is ad-hoc signed, not notarised by Apple, so macOS asks you to approve it on first launch.
  • Because it isn't signed with a Developer ID, macOS forgets its permissions after each update; allow them again in Settings › System.
  • MeetMind tells you when an update is out and opens the release page; you install it by downloading the new DMG.
  • Meeting detection is planned but not available yet.

Found something that doesn't work on your Mac? Report it on GitHub; there is no maintainer Mac, so tester reports shape the beta.

Frequently asked questions

Why does it need macOS 14.2?

macOS 14.2 added the Core Audio API that lets an app record system audio without a virtual audio driver such as BlackHole. Earlier versions don't have it.

Why does it ask for Screen & System Audio Recording?

macOS puts system audio capture under that permission. MeetMind keeps only the audio and discards the video track.

Does it work on Apple silicon and Intel?

Yes. There is a separate download for each: arm64 for M-series Macs and x64 for Intel.

How do I know the download is genuine?

Every release file has a signed build attestation. Run gh attestation verify MeetMind-x.y.z-arm64.dmg --repo aslahtp/meetmind with the GitHub CLI to confirm it was built from the public source.
