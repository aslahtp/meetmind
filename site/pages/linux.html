AI meeting notes for Linux, free and open source

MeetMind records any call through PulseAudio or PipeWire, notices when Zoom, Google Meet or Teams starts, and writes a transcript and minutes with decisions and action items. AppImage and .deb.

In short

MeetMind for Linux is a free beta for x64 desktops such as Ubuntu 22.04, Debian 12, Fedora 38 or newer. It records what your default output device plays (the other participants) and your default microphone through PulseAudio or PipeWire, so it works with any meeting app and no bot. It needs pactl from the pulseaudio-utils package, which most desktops already have.

Install MeetMind on Linux

.deb (Ubuntu, Debian and derivatives)

  1. Download MeetMind-x.y.z-amd64.deb from the latest release.
  2. Install it with sudo apt install ./MeetMind-x.y.z-amd64.deb.
  3. To update, install the new .deb the same way; MeetMind tells you when one is out.

AppImage (any distribution)

  1. Download MeetMind-x.y.z-x86_64.AppImage.
  2. Make it executable with chmod +x MeetMind-*.AppImage and run it.
  3. AppImages need FUSE 2: on Ubuntu 24.04 and later, sudo apt install libfuse2t64.
  4. The AppImage updates itself.

Then

Play a video and use Settings › System › System audio › Test to check that MeetMind hears your computer; the same card shows whether pactl found your audio server. Add your speech-to-text and notes keys in Settings. FFmpeg is included.

Meeting detection on Linux

MeetMind reads which apps are using the microphone from PulseAudio or PipeWire and offers to record when a meeting starts:

  • Zoom desktop app and teams-for-linux count as soon as they use the microphone, on X11 and Wayland.
  • Browser meetings (Google Meet, Zoom or Teams in Chrome, Edge, Brave, Firefox, Opera or Vivaldi) are recognised from window titles, which only X11 exposes. MeetMind runs through XWayland when it can; on a Wayland-only session, press Record or use the Chrome extension.

The prompt is a slim overlay at the top of the screen; if it can't be shown, a desktop notification offers to record instead.

Other details

  • Start at login adds an XDG autostart entry (~/.config/autostart/meetmind.desktop).
  • If the normal capture can't start, MeetMind falls back to recording the default output's monitor and the default input with FFmpeg's PulseAudio input.
  • meetmind:// links open the app when it is installed from the .deb.

Frequently asked questions

Does it work with PipeWire?

Yes, through PipeWire's PulseAudio compatibility layer (pipewire-pulse), which most PipeWire desktops run by default. pactl must be installed.

Does it work on Wayland?

Recording works on Wayland. Detecting browser meetings needs window titles, which Wayland hides, so on a Wayland-only session MeetMind detects the Zoom and teams-for-linux apps but not browser tabs.

Is there an ARM build?

Not yet; the Linux beta is x64 only.

Something doesn't work on my distribution.

Please open an issue with your distribution, desktop and the result of the system audio test. The beta is shaped by tester reports.
